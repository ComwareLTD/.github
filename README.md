 # .github — 이슈 / PR 템플릿 저장소

  이 저장소는 GitHub 이슈와 Pull Request를 등록할 때 자동으로 채워지는 **공통 양식**을 모아 둔 곳입니다.
  소스코드는 없고 양식 파일만 있습니다.

  > 🧪 **시험 운영 중입니다.** 양식이 불편하거나 빠진 항목이 있으면 누구든 자유롭게 수정해 주세요.
  > 승인 없이 바로 고쳐도 됩니다. 써 보면서 같이 다듬는 게 목적입니다.

  ## 어떻게 동작하나

  GitHub는 계정(또는 조직) 안에 이름이 `.github`인 저장소가 있으면, 그 안의 양식을 **다른 모든 저장소에 자동
  적용**합니다.
  그래서 FMS, API 같은 실제 코드 저장소를 건드리지 않고도 양식을 넣을 수 있습니다.

  - 이슈 등록: Issues → New issue 를 누르면 양식 선택 화면이 뜹니다.
  - PR 등록: New pull request 를 열면 본문에 양식이 미리 채워집니다.

  ## 수정 방법

  1. 고치고 싶은 파일을 열고 연필(Edit) 아이콘 클릭
  2. 내용 수정 후 Commit changes
  3. 반영까지 1~2분 걸릴 수 있습니다
  4. 파일 맨 위 `---` 로 감싼 블록(name, about, title, labels)은 GitHub가 읽는 설정이니 지우지 마세요. 


  ## 사용 규칙

  - 이슈와 PR 제목은 회사 관리번호 `[xxxx-xxx]` 로 시작합니다. 예: `[2606-010] 브랜드등록 저장 오류`
  - PR 본문의 `closes #이슈번호` 에 GitHub 이슈 번호를 넣으면 머지 시 이슈가 자동으로 닫힙니다.
  - 이슈·PR 어디에도 DB 접속정보, 계정/비밀번호, 개인정보(주민번호·전화번호 등)는 적지 않습니다. 로그와 스크린샷은
  마스킹 후 첨부합니다.

  ## 의견

  양식에 대한 의견은 이 저장소 Issues 에 남기거나, 그냥 바로 고쳐 주세요.
